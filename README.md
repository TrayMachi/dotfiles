# dotfiles

Personal [Arch Linux](https://archlinux.org) configuration, managed with `rsync` via a [Makefile](Makefile).

## Contents

| Directory   | Mirrors                          | Notes                                      |
|-------------|----------------------------------|--------------------------------------------|
| `fish/`     | `~/.config/fish/`                | Shell config (conf.d, functions, completions) |
| `hypr/`     | `~/.config/hypr/`                | Hyprland (entrypoint: `hyprland.lua`)      |
| `niri/`     | `~/.config/niri/`                | Niri (entrypoint: `config.kdl`)            |
| `kitty/`    | `~/.config/kitty/`               | Terminal emulator                          |
| `zed/`      | `~/.config/zed/`                 | Zed editor                                 |
| `fastfetch/`| `~/.config/fastfetch/`           | System info fetch                          |
| `opencode/` | `~/.config/opencode/`            | opencode CLI config                        |
| `agents/`   | `~/.agents/`                     | Agent skills and installer metadata        |

## Usage

- `make diff` / `make diff-<component>` — compare system config against the repo (do this first).
- `make backup` / `make backup-<component>` — copy **system → repo** with `rsync --delete`.
- `make restore-<component>` — copy **repo → system** with `rsync --delete`.
- `make confirm-restore-<component>` — same as restore, but skips the confirmation prompt.

> [!CAUTION]
> `make` defaults to `backup`, which overwrites the repository with your current system state. Never run `make`, `make backup`, or a `backup-*` target unless you intend the system to replace the repo. Always `make diff-<component>` first, and prefer single-component targets.

## Notes

- Credentials stay out of tracked files: `fish/conf.d/secrets.fish` is gitignored and `opencode/opencode.json` references secrets via `{env:...}` placeholders.
- `hypr/monitors.lua` and `hypr/monitors.conf` are generated by `nwg-displays` — regenerate, don't hand-edit.
- `hypr/hyprland/` and `hypr/dms/` are imported defaults; put personal overrides in `hypr/custom/`.
- `agents/` contains installer-managed skills — change them through their installer, not by hand.
- `niri/config.kdl.backup.*` files are automatic backups from the entrypoint; safe to ignore.
